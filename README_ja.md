# Streamlit 簡単サンプルアプリ

このリポジトリでは、Python ライブラリの Streamlit を使ったシンプルな Web アプリの例を紹介しています。

---

## ✅ 概要

Streamlit は、Python コードだけでデータアプリケーションを作成できるオープンソースのライブラリです。

---

## 🧰 必要な環境

* Python 3.7 以上
* pip

---

## 📦 インストール方法

以下のコマンドで必要なライブラリをインストールできます：

```bash
pip install streamlit
```

または、`requirements.txt` からまとめてインストール：

```bash
pip install -r requirements.txt
```

---

## 🚀 アプリの実行方法

以下のコマンドでアプリを起動します：

```bash
streamlit run run.py
```

ブラウザが自動的に開きます。開かない場合は以下にアクセスしてください：
http://localhost:8501

> **注意:** グローバルの `~/.streamlit/config.toml` を変更する必要はありません。このプロジェクトには適切なデフォルト値が設定された `.streamlit/config.toml` が含まれています。

---

## ⚠️ うまく動かない場合

> **ほとんどの場合、`streamlit run run.py` を実行するだけで動きます。設定の変更は不要です。**
> このプロジェクトに付属する `.streamlit/config.toml` はすべてコメントアウトされた状態です。Streamlit の組み込みデフォルトはローカル開発に最適です。**グローバルの `~/.streamlit/config.toml` を変更しないでください。**
>
> 問題が起きた場合は、下の表から自分の状況に合うものを探して、**該当する修正だけを**試してください。

### まず最初に：クイックセルフチェック

設定を変更する前に、問題の範囲を絞り込みましょう：

1. **Streamlit 自体は動きますか？** `streamlit hello` を試してください — 組み込みデモが動けば、環境は正常で、問題はアプリコード側です。
2. **URL にアクセスできますか？** ブラウザで [http://localhost:8501](http://localhost:8501) を開いてください。読み込めれば、アプリは正常に動いており、ブラウザの自動起動だけが問題です。
3. **コマンドが起動時に失敗しましたか？** ターミナルのエラーを読んでください。最も多いのはポート衝突で、以下で説明しています。

### 状況 A：「Port 8501 is already in use」と表示される

ポート 8501 が他のプロセスに使われています。2 つの直し方があるので、どちらかを選んでください：

* **コマンドライン引数（一番早い、ファイル編集なし）：**

  ```bash
  streamlit run run.py --server.port 8502
  ```

  起動後、[http://localhost:8502](http://localhost:8502) にアクセスしてください。

* **恒久的な修正：** `.streamlit/config.toml` で `port = 8501` のコメントを外し、任意のポート番号に変更します。

### 状況 B：アプリは動いているがブラウザが開かない

WSL、SSH、Docker などのヘッドレス環境では正常な動作です。ブラウザを手動で開き、[http://localhost:8501](http://localhost:8501) にアクセスしてください。

今後もブラウザを自動起動させたくない場合は、`.streamlit/config.toml` で `headless = true` のコメントを外してください。

### 状況 C：同じネットワーク内の別の端末からアクセスしたい

デフォルトでは Streamlit は `localhost` にのみバインドされており、他のマシンからは接続できません。これはセキュリティ上の意図された仕様です。

LAN からのアクセスを許可するには、`.streamlit/config.toml` で以下の行のコメントを外してください：

```toml
address = "0.0.0.0"
```

その後、マシンのローカル IP を使ってアクセスしてください（例：`http://192.168.x.x:8501`）。

> **⚠️ セキュリティ上の注意:** これにより、ネットワーク上の誰でもアプリにアクセスできるようになります。信頼できるネットワーク内でのみ使用し、Streamlit を直接インターネットに公開しないでください。

### 状況 D：ブラウザのコンソールに CORS エラーが出る

これはリバースプロキシ（nginx、Caddy）の背後や特定のクラウド環境でのみ発生します。通常のローカル開発では**発生しません**。

自分の環境に当てはまることが確実な場合のみ、`.streamlit/config.toml` で以下の行のコメントを外してください：

```toml
enableCORS = false
```

> **ローカル（`localhost`）開発ではこの設定を変更しないでください** — メリットがなく、ブラウザのセキュリティが低下します。

### まとめ：どの修正が必要？

| 表示される内容 | 状況 | 修正方法 |
|---|---|---|
| `Port 8501 is already in use` | A | `--server.port` 引数を使用 |
| ターミナルに「running」と出るがブラウザが開かない | B | URL を手動で開く |
| 別の端末から接続が拒否される | C | config.toml で `address` のコメントを外す |
| ブラウザの開発者ツールに CORS エラー | D | config.toml で `enableCORS` のコメントを外す |
| 上記のどれにも当てはまらない | — | `streamlit hello` を実行して環境を確認 |

### それでも動かない場合：環境の基本チェック

上記のどれにも当てはまらない場合は、基本を確認してください：

1. `python --version` — 3.7 以上であること。
2. `streamlit --version` — バージョン番号が表示されること。
3. `streamlit hello` — 組み込みデモが動けば、問題はアプリコード側にあり、環境の問題ではありません。
